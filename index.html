GOOD TO KNOW

Frequently asked questions

Clear answers before you get started.

Are my files uploaded to a server?+

No. Supported PDF operations run locally in your browser. The site loads third-party JavaScript libraries from CDNs, but your document contents are not sent to those CDNs by this app.

Can PDFPro remove any watermark?+

No. Removing a watermark reliably requires identifying and editing the original PDF objects. A watermark may be flattened into page content, overlap other text, or be protected. PDFPro does not offer automatic watermark removal because it cannot guarantee a clean result.

Why are some PDF features limited?+

Some document operations require specialized PDF engines. PDFPro only lists tools that have an implementation in this browser build.

Is there a file size limit?+

PDFPro applies a 100 MB per-file safety limit. Large documents may still use substantial memory and may process slowly depending on your device and browser.

Does PDFPro work on phones?+

Yes. The layout adapts to phones and tablets. For very large PDFs, a laptop or desktop generally provides more memory and a better processing experience.
